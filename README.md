# Blocks
A Tetris-inspired game for Sidephone SP-01.

## Tetris Score System

1 line: 2 * (1 + level)
2 lines: 5 * (1 + level)
3 lines: 15 * (1 + level)
4 lines: 60 * (1 + level)

10 lines = next level
